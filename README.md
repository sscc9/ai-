# 🐺 AI 狼人杀 — 大模型真实智商竞技场

**让 AI 打一局狼人杀，比任何排行榜都更能看出它有多聪明。**

这不只是一个游戏。这是一个**大模型真实能力评估平台**。通过一局完整的狼人杀对局，你可以直观地看到一个 AI 模型的逻辑推理、信息博弈、伪装欺骗、说服煽动和漏洞识别能力——这些能力在传统基准测试（MMLU、GPQA 等）中是完全无法被衡量的。

## 🎯 为什么狼人杀能测出 AI 的真实智商？

传统排行榜可以通过刷题库和微调来获得高分，那只是"应试教育"。
狼人杀是一个**多角色、非完全信息、多轮动态博弈**的社交推理游戏，它能测试以下核心能力：

| 评估维度 | 传统排行榜 | 狼人杀对局 |
| :--- | :---: | :---: |
| **心智理论** — 推测"别人知道什么" | ❌ | ✅ |
| **逻辑一致性** — 多轮对话中不自相矛盾 | ⚠️ 单轮 | ✅ 多轮 |
| **信息过滤** — 从嘈杂发言中提炼关键线索 | ❌ | ✅ |
| **伪装与说服** — 编造可信谎言，煽动他人跟票 | ❌ | ✅ |
| **漏洞识别** — 听出别人发言中的逻辑硬伤 | ⚠️ 静态 | ✅ 实时 |
| **时序推理** — 区分"第一晚没有信息"和"第二天有历史" | ❌ | ✅ |

**一个聪明的模型**：能在竞选中识破假预言家的双标攻击，能在狼夜精准分配刀口，能用逻辑说服全场跟票。

**一个不够聪明的模型**：会编造时间线上不存在的证据，会听不出对手发言中的规则级漏洞，会被气势强的假话蒙骗投票。

## ⚖️ 公平性设计

本项目的系统提示词（System Prompt）经过精心设计，确保对所有模型**绝对公平**：

- **只提供客观信息，不提供决策指导**：提示词只传递游戏状态（时间线、存活玩家、历史发言），不教 AI 怎么玩、怎么骗、怎么投票。
- **没有给笨模型打补丁**：不会因为某些模型容易犯错就加入额外的教学提示——这些补丁表面上是在帮笨模型，实际上会干扰聪明模型的自主判断，反而拉低了聪明模型的发挥上限。
- **所有战术、伪装、说服、站队，全部由模型自主决策。**

提示词就像一张无偏差的棋盘——棋盘上没有给任何一方设限或提供外挂，下棋水平的高低，完全由模型自己的脑子决定。

> [!CAUTION]
> **不建议修改系统提示词（System Prompt）。** 当前的提示词结构已经过反复验证，确保对所有智力水平的模型保持公平。任何针对特定模型弱点的"补丁"式修改，都可能破坏这种公平性——为笨模型加的教学提示，往往会成为聪明模型的思维枷锁。如果对局中出现低质量发言，那是模型本身的能力问题，不是提示词的问题。

## ✨ 核心功能

- **多模型同台竞技**：支持 Gemini、DeepSeek、OpenAI、GLM 等多个模型同局对战，每个玩家可配置不同模型。
- **完整狼人杀流程**：守卫→狼人→预言家→女巫→天亮→警长竞选→发言→投票→遗言，全自动流转。
- **人机混战**：你可以作为玩家加入对局，与 AI 们同场博弈。
- **音画同步回放**：支持 TTS 语音播报、时间旅行回放与剧场模式。
- **高自由度定制**：可配置每个角色的模型、温度、音色、个性化策略提示词。
- **动态天气与主题**：沉浸式视觉体验，夜间天气特效与平滑音效。

## 快速开始

本项目由前端（Vite 开发服务器）和后端（FastAPI TTS 服务）两部分组成。

### 1. 后端 TTS 服务配置与启动

后端使用 Python 执行 Edge-TTS 接口，提供免费且高质量的语音合成服务。

#### 安装步骤：
1. 确保系统已安装 Python 3.10+。
2. 进入 `server` 目录：
   ```bash
   cd server
   ```
3. 创建虚拟环境并激活：
   * **Windows**:
     ```powershell
     python -m venv venv
     venv\Scripts\activate
     ```
   * **macOS/Linux**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
4. 安装 Python 依赖：
   ```bash
   pip install -r requirements.txt
   ```

#### 启动后端：
* 直接运行 Python 脚本：
  ```bash
  python main.py
  ```
* 或者在项目根目录下双击运行 `start_tts_backend.bat` (Windows) 或执行 `start_tts_backend.sh` (macOS/Linux)。

后端将在 `http://localhost:8000` 启动服务。

### 2. 前端服务安装与启动

前端采用 Vite 进行模块打包和本地热更新，利用 `http-proxy` 代理请求到后端。

#### 安装步骤：
1. 确保系统已安装 Node.js (推荐 18+ 或 20+)。
2. 在项目根目录下，安装 Node 依赖包：
   ```bash
   npm install
   ```

#### 配置 API Key：
启动应用后，直接在浏览器网页的右上角点击 **设置 (Settings ⚙️)** 图标，配置您个人的 Google Gemini 或 DeepSeek 等模型的 API Key 即可。

#### 启动前端：
在根目录下运行以下命令启动本地开发服务器：
```bash
npm run dev
```
前端开发服务器将在 `http://localhost:3000` 启动，您可以通过浏览器访问它。

* **Windows 一键启动**：根目录下提供了 `start_app.bat`，双击可自动开启后端 TTS 虚拟环境并并行启动前端 Vite。

> [!NOTE]
> **零 Key 泄露风险**：
> 本项目已彻底移除了在编译打包时将外部 Key 注入打包产物的行为。
>
> 页面中所有大模型 API Key 均**完全由用户自行在网页"设置⚙️"界面配置**，且仅加密或直接保存在玩家本地浏览器的 `localStorage` 中。公开部署上线此网页（例如使用 Vercel 或 GitHub Pages）完全不用担心密钥被泄露。

## 架构与核心逻辑

* **`atoms.ts`**：Jotai 的全局状态原子库，负责定义核心的角色名单、游戏阶段、上帝笔记本、日志归档等底层数据结构。
* **`store.ts`**：派生状态与事务动作，提供游戏初始化、历史快照保存和回放逻辑。
* **`hooks/useGameEngine.ts`**：游戏主引擎。通过轮询驱动各阶段的游戏转换。包含 AI 投票的 JSON 重新呼叫和纠错机制。
* **`hooks/useTheaterEngine.ts`**：音频剧场级播放引擎。通过结构化的 `log.deaths` 属性准确还原现场死亡状态，剔除了不稳定的正则自然语言反推。
* **`services/skills/werewolf/WerewolfSkill.ts`**：狼人杀专有技能类，用于根据游戏上下文为每个玩家组装最优提示词。
* **`services/llm.ts`**：通用大模型网关层，支持 Gemini SDK 的结构化多轮 `contents` 会话，并能够自适应预设中配置的思维链属性和温度参数。
